# โน้ตผู้สาธิต — ทดสอบ Error เดือนมีนาคม (สื่อสอน ไม่ใช่ส่วนของระบบที่รัน)

> เอกสารนี้อยู่นอกระบบที่รัน ระบบไม่อ่านไฟล์นี้ และไม่แสดงเฉลยบนหน้าจอ

## เกิดอะไรขึ้นกับมีนาคม
- ไฟล์ `Fact_Order_Items.csv` ของเดือนมีนาคม แถวแรก (`ORD-202603-00001-I1`) มี `SKU_ID = SKU_ERR_UNKNOWN_DEMO` ซึ่งไม่มีใน `Dim_SKU`
- ระบบตรวจกฎความสัมพันธ์ข้อมูล (REFERENCE_EXISTS) จึง **หยุดก่อน Publish** (สถานะ BLOCKED_DQ) ข้อมูลเดือน ม.ค. และ ก.พ. ที่ Publish แล้วไม่ถูกแตะ

## ค่าที่ต้องเลือก และที่มา (ต้องพูดให้ผู้ชมรู้)
- ค่าที่ถูกต้องสำหรับแถวนี้ในชุดข้อมูลสาธิตคือ **`PG01-BL-M`** (คอกลม สีดำ ไซส์ M)
- **ที่มา:** มาจากไฟล์เฉลยของชุดข้อมูล Final (ส่วน QA `fix_patch_2026_03_invalid_sku.json`) ที่เตรียมไว้ล่วงหน้า **ระบบหาค่านี้เองไม่ได้** และไม่เปิดเผยบนหน้าจอ
- ตัวช่วยบนหน้าจอบอกได้แค่ว่าราคาขาย 199 ตรงกับกลุ่ม PG01 (มี 28 SKU ราคาเท่ากัน) ไม่บอกสี/ไซส์

## ความเสี่ยงที่ต้องอธิบาย
- ระบบรับ SKU ใดก็ได้ที่มีใน `Dim_SKU` ถ้าเลือกผิด (เช่น `PG01-BL-S`) การตรวจซ้ำจะ **ผ่าน** และ March Publish ได้
- ระบบตรวจได้เพียง "มีใน Master ไหม" ตรวจไม่ได้ว่า "ตรงกับของจริงไหม" จึงต้องมีคนยืนยันจากเอกสารต้นฉบับ และระบบบันทึกชื่อผู้ยืนยัน เหตุผล หลักฐาน และเวลาไว้ทุกครั้ง

## ขั้นตอนสาธิต (ประมาณ 1 นาที)
1. รัน March → หน้าจอแจ้ง "ข้อมูลไม่ผ่านการตรวจคุณภาพ" และหยุดก่อน Publish
2. กด Review & Fix → อ่านปัญหาในหนึ่งบรรทัด (ดูรายละเอียดหลักฐานได้)
3. เลือก `PG01-BL-M` (อธิบายที่มาจากเอกสารต้นฉบับ) → ใส่ชื่อผู้ยืนยัน
4. กด "ยืนยันแก้ไขและรันต่อ" → บันทึก → ตรวจซ้ำ → รันต่อ → March Publish
5. เปิดหน้า Neon/ประวัติเพื่อโชว์ว่าการแก้ไขถูกบันทึกแบบเพิ่มต่อท้าย ไม่แก้ทับต้นฉบับ
