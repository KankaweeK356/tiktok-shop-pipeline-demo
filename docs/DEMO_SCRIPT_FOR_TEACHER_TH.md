# บทพูด Demo สำหรับอาจารย์

## ลำดับนำเสนอ

1. **ภาพรวมธุรกิจ:** เปิด Dashboard แล้วชี้ KPI ยอดขายเทียบเป้าและเกณฑ์กำไรขั้นต่ำ 10% จาก Warehouse ปัจจุบัน
2. **Pipeline:** เปิด Test Pipeline กด Run 1 หนึ่งครั้ง ระบบทำครบ Source → Database → Data Lake → Warehouse → Validation
3. **อ่านผล:** เปิดแต่ละขั้นดูตารางและตัวอย่างข้อมูลจริง สรุปจำนวนก่อน–หลัง เวลารัน และผลตรวจ
4. **เติมเดือนใหม่:** กดเติมข้อมูลเดือนถัดไป ระบบเพิ่มทีละเดือนใน Lab เดิม; Run 1 ยังคงแสดงว่าผ่านแล้ว
5. **กรณีผิดพลาด:** เปิด Error Test แยก ดูว่าปัญหาเกิดที่ไหน ระบบตรวจพบอะไร และผลหลังลองกู้คืน
6. **ML:** เปิด ML Lab ชี้ Feature ที่สร้างจาก Warehouse, การแบ่ง Train/Validation/Test ตามเวลา และ WAPE. ปุ่มฝึกเปิดเมื่อมีสัปดาห์ Feature ที่ครบอย่างน้อย 16 สัปดาห์

## คำอธิบายสั้น ๆ

“Run 1 นำข้อมูลเดือนมกราคมเข้าระบบ ส่วนการเติมข้อมูลจะเพิ่ม Source เดือนถัดไปครั้งละหนึ่งชุด ทุกครั้งเดินครบ Pipeline และมีผลตรวจให้ดู เราแยก Error Test ออกจากข้อมูลปกติเพื่อให้สาธิตการตรวจพบและกู้คืนได้โดยไม่ทำให้ข้อมูลธุรกิจเสียหาย”
