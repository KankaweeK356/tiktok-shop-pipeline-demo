# การแชร์และตรวจผล Demo

## แชร์ให้ผู้ชม

- เว็บสำหรับดู Dashboard และรัน Lab ร่วมกัน: [TikTok Shop Classroom Demo](https://tiktok-shop-mlops-dashboard-git-feature-classroom-dea39b-newja.vercel.app/)
- Colab สำรองแบบพื้นที่ส่วนตัว: [Pipeline Notebook](https://colab.research.google.com/github/KankaweeK356/tiktok-shop-pipeline-demo/blob/feature/classroom-demo-evidence-foundation/notebooks/TikTok_Shop_Step_by_Step_Demo.ipynb)

## ใช้ Colab

เลือก **Runtime → Run all** เพื่อเตรียมโปรเจกต์ แล้วกดปุ่มเริ่ม Run 1 และเติมเดือนถัดไปทีละชุด. ผลลัพธ์อยู่ใน Runtime ของผู้รันและไม่ส่งกลับ GitHub หรือเว็บอัตโนมัติ

## ใช้ GitHub

Source รายเดือน, Schema, Pipeline, Notebook และคู่มืออยู่ใน Repository นี้. การแก้ไข Repository จะเป็นต้นฉบับที่ใช้กับเว็บ Preview และ Notebook. ไฟล์ผลส่วนบุคคลจาก Colabไม่ควรอัปโหลดทับ Source หรือฐานข้อมูล; แชร์ผลด้วยการเปิด Notebook ให้ดู หรือดาวน์โหลดไฟล์จาก Runtime เมื่อจำเป็น
