# การปรับหน้าวางแผน / เทียบผลจริง / ML (รอบ 21 พ.ย. 2569)

แก้เฉพาะหน้าจอ (`dashboard/app.js`, `styles.css`) และตัวส่งข้อมูลเทียบแผน (`lib/lab-forecast.js` อ่านข้อมูลเดิม) **ไม่เปลี่ยนการคำนวณแผน Forecast ML หรือข้อมูล**

| # | สิ่งที่แก้ | ผล |
| :--- | :--- | :--- |
| E2 | ข้อความ error ตอนบันทึกแผน/Seal/Generate เคยถูกล้างทิ้งตอนโหลดหน้าซ้ำ | ตอนนี้เก็บผลของการกดล่าสุดแยกต่างหาก แสดงใกล้ปุ่ม |
| E | ไม่มีการบอกว่าบันทึกสำเร็จ | แบนเนอร์เขียว “บันทึกแผนเวอร์ชัน N สำเร็จ · ผู้บันทึก · เวลา” ป้าย “✓ บันทึกแล้ว เวอร์ชัน N” ปุ่มเปลี่ยนเป็น “ตรวจผลก่อนบันทึก →” |
| B | ข้อความอธิบาย | เดือนที่ Publish แล้วขึ้นว่าบันทึกแผนไม่ได้ (ปุ่มล็อก) · อธิบาย Official Forecast vs Scenario Net · หน้าเทียบผลเตือนว่าส่วนต่างรวมผลของแผน |
| A | ตารางเทียบแผนกับผลจริง | แยก “ทำตามแผนไหม” (Ads, Campaign, Voucher, Affiliate, ตัวอย่างฟรี) / “ผลที่ได้” (ยอดรวม ยอดขายสุทธิ กำไร) / เกณฑ์ 3 ข้อ พร้อม % และข้อมูลแผน |
| D | ML | หน้าวางแผนเหลือบรรทัดลิงก์ · หน้าเทียบผลจริงมีสรุป 3 ข้อ (ML ดีกว่าไหม / ข้อมูลพอไหม / ต้องทำอะไร) และ “ดูรายละเอียด ML” พับไว้ · ศัพท์เป็นภาษาที่เข้าใจง่าย |
