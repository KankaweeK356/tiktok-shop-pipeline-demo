# Source fixtures และ Source รายเดือน\n\nข้อมูลทั้งหมดเป็นข้อมูลสังเคราะห์เพื่อการศึกษา ไม่ได้ดึงจาก TikTok Shop API และไม่มีข้อมูลลูกค้าหรือการเงินจริง\n\n## แยกชุดข้อมูลเก่ากับ Flow ปัจจุบัน\n\nไฟล์ CSV ในโฟลเดอร์ `source/initial/` และ `source/incremental/` เป็น fixture รุ่นเดิม: October 2026 มี 800 Orders และ November 2026 มี 100 Orders ใหม่ พร้อมกรณีเปลี่ยนสถานะ/ปรับข้อมูลปลายงวด. ใช้สำหรับทดสอบ legacy October→November และเป็นส่วนตั้งต้นของข้อมูลจำลองย้อนหลังบาง workflow เท่านั้น\n\n**ตัวเลข 800/100 ไม่ใช่จำนวน Run 1/Run 2 ของ Flow ปัจจุบัน**. Colab Step-by-Step และ Classroom Web ใช้ `pipeline/generate_classroom_source.py` สร้าง Source 10 ชุดรายเดือน January–October 2026. Run 1 คือ January; การเติมแต่ละครั้งคือเดือนถัดไปหนึ่งเดือน. จำนวนแต่ละเดือนอ่านจาก manifest และผล Pipeline จริง ไม่ได้ล็อกให้เพิ่ม 100 Orders. Fixture October 800 Orders อยู่ในชุด October; fixture November 100 Orders ไม่อยู่ในช่วง Source ปัจจุบัน\n\nทุก delivery รายเดือนมี 21 CSV ตาม ER1 contract และหัวคอลัมน์ชุดเดียวกัน. Master/Reference เริ่มต้นที่ Run 1; delivery ถัดไปคงไฟล์ Master/Reference ไว้ตาม schema และเพิ่มข้อมูลธุรกิจของเดือนนั้น. ER1 มี 25 ตาราง โดย 4 ตารางคำนวณจาก Pipeline ไม่ได้ส่งเป็น Source CSV. ราคา ส่วนลด COGS และ Commission บางค่าได้จากกฎใน Pipeline ไม่ใช่ค่าที่บันทึกมาใน CSV.\n\nดู [ตัวสร้าง Source รายเดือน](../pipeline/generate_classroom_source.py), [manifest contract](../dashboard/data/classroom_source_contract.json) และ [คู่มือปัจจุบัน](../docs/QUICK_START_TH.md).\n
